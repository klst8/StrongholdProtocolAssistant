# 卫戍选调助手

Windows 桌面工具，面向《明日方舟》国服「卫戍协议·规程」。启动后自动查找 `Arknights.exe` 的游戏窗口；检测到进入卫戍协议后自动开始识别和记录。

## 启动

从 [GitHub Releases](https://github.com/klst8/StrongholdProtocolAssistant/releases) 下载 Windows 64 位免安装版 `StrongholdProtocolAssistant.exe`，双击即可打开，无需安装 Python。识别功能依赖 Windows 的简体中文 OCR 语言功能。免安装版把阵容、自选历史、界面配色和日志保存在 `%LOCALAPPDATA%\StrongholdProtocolAssistant`。

点击窗口右上角的「配色」，可在海蓝、深夜和暖砂之间切换。配色立即生效，重启后保留。

点击标题栏的最小化按钮，助手会收成可拖动的「卫」字悬浮球。单击悬浮球恢复主窗口。收起期间，游戏识别、对局记录和卡牌推荐提示会继续运行。

维护者可在安装项目依赖和 PyInstaller 后运行 `python -m PyInstaller StrongholdProtocolAssistant.spec`，生成 `dist/StrongholdProtocolAssistant.exe`。

在 Windows 上双击 `start_assistant.pyw` 可直接打开助手窗口。需要查看启动报错时，可运行 `start_assistant.bat`。

在此目录打开 PowerShell。需要 Python 3.10 或更新版本，以及 Windows 的简体中文光学字符识别语言功能。若助手提示缺少 OCR，可在 Windows 的「设置 → 时间和语言 → 语言和区域 → 中文（简体，中国）→ 语言选项」中检查光学字符识别功能。

```powershell
python -m pip install -r requirements.txt
python assistant.py
```

## 对局中使用

1. 用窗口模式启动游戏，等右侧「连接设置」显示「已找到」。把助手挪到游戏窗口旁边，避免遮住画面。需要时可在这里勾选「窗口置顶」。
2. 助手会持续识别游戏画面，在进入卫戍协议大厅或难度选择页时自动开始记录。切出后会尝试后台截图；游戏最小化或无法提供后台画面时暂停，重新取得画面后继续。回到卫戍协议大厅（本局结束）或游戏主界面时结束本局记录。
3. 打开局内候选干员面板。筹备界面会根据「升级」卡的位置定位不同商店等级的干员和装备卡片，并记录回合、血量和倒计时。V、VI 级按一件装备和六名干员的布局处理，实际位置待用实机截图验证。若需手动定位，点「框选候选区」，在最近一帧画面上标定候选名字的位置，随后切回游戏。点击「恢复自动」可清除手动区域。
4. 点开干员或装备详情时，助手会记录读到的名称。如果同屏显示已持有干员名称，可以点「框选队伍」。头像界面可使用「已持有干员补录」，用空格或逗号分隔名称。
5. 每次自动识别到卫戍协议时，会在 `sessions` 创建独立的 JSONL 文件，保存时间、阶段判断、OCR 原文及识别出的阵容状态。若从大厅开始记录，也会保存难度页当时的选择和读到的搜寻方式。连续相同的识别结果只记录一次。文件仅保存文字和结构化结果，最近一帧截图在内存中供框选。

右侧「实时截图」在连接游戏后通过 Windows 窗口预览显示实时画面。窗口预览不可用时，会显示最近一次识别截图。「运行日志」显示连接、自动开始、暂停、阶段变化、错误和保存结果。

自动定位到商店卡槽时，助手会用发光手指指向推荐卡牌，并给推荐干员的卡牌加红框。提示随识别更新，鼠标可穿透。手动框选候选区时，干员推荐显示在侧窗。

## 导入阵容

「保存阵容」会保存本局追踪的干员和装备，也支持只保存装备。在「我的阵容」打开已保存的阵容，再点「复制阵容码」即可分享。

在顶部输入框粘贴阵容码，按回车或点击「导入阵容码」打开「阵容预览」。双击干员或装备图标可逐个追踪，也可以点「一键追踪」加入整套。旧阵容码仍可导入。

## 按策略盟约推荐

助手读到自己的策略预览，并识别到选择阶段向后推进时，会用该预览推断选定的策略。识别到对应十个核心盟约之一的策略后，若已导入预设，侧窗会问「是否按照盟约推荐干员？」。选「是」后，本局按该盟约推荐商店里尚未确认持有的干员。选「否」继续按预设推荐。未导入预设时自动使用该盟约。

也可以直接点击左侧十个盟约按钮切换推荐阵容；勾选标记表示当前使用的盟约。按钮下方显示 PRTS 的干员头像，黄色边框表示当前商店里可推荐的目标。头像已保存到 `assets/avatars`，程序可离线读取。新增干员时运行 `python download_avatars.py` 可从 [PRTS 盟约记录](https://prts.wiki/w/卫戍协议·规程/PRTS盟约记录) 更新头像缓存。主窗口默认以较紧凑尺寸显示在屏幕左下方，可拖动到游戏窗口旁边。

盟约所属干员使用 [SquadPool 的《卫戍协议：规程》图鉴](https://squad-pool.com/arknights-pacts)。策略推断依赖预览名称可读，场上模型的身份仍需视觉识别校准。
